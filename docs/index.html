The math behind the idea

The algebra of
a composed shell.

Small, independent pieces give us three useful laws. Here, ⊕ means combining peer configuration, and ≈ means equivalent configured behavior.

Commutativity

A ⊕ B
≈ B ⊕ A

Change the order. Loading the same peers in a different order gives you the same configured behavior.

Associativity

(A ⊕ B) ⊕ C
≈ A ⊕ (B ⊕ C)

Change the grouping. Organize peers into folders that make sense to you. Grouping adds no loading phase.

Idempotence

A ⊕ A
≈ A

Load it again. Re-sourcing an unchanged peer preserves its setup without stacking duplicate hooks or registrations.

Composition combines pieces into a workflow; its steps can depend on order. These laws govern peer setup under the same prerequisites and ownership rules, with capabilities checked at invocation. Compare behavior after loading finishes. The optional initializer still loads first and sits outside these laws. Runtime operations keep their sequence: capture candidates, then filter, then act. Regression tests check the shell contract; this model illustrates it.

03 / Make yourself at home

Your setup.
On your terms.

The installer shows its plan, backs up what it replaces, and leaves your private configuration intact.

REQUIRES

macOS · Zsh 5.9+ · Git

Check your environment ↗
01

Give it a home.

Clone once into a stable location. Already cloned? Set repo_dir to that folder instead.

repo_dir="$HOME/Projects/compozsh"
git clone https://github.com/bitbemol/compozsh.git "$repo_dir"
02

Look before you link.

A dry run previews the plan and leaves your files unchanged.

zsh "$repo_dir/install.zsh" --symlink --dry-run
03

Make it yours.

Run the installer, review the plan, and confirm. After it succeeds, start a fresh shell.

zsh "$repo_dir/install.zsh" --symlink
exec zsh

Already have a .zshrc?

Keep it as it is. The installer archives the active file before replacing it. Move your personal setup into the private initializer or focused add-ons.

Full installation and recovery guide →
Enable Option shortcuts.

In Terminal → Settings → Profiles → your profile → Keyboard, enable Use Option as Meta key. Option-I pins the Context lens, Option-Tab opens Recents, and Option-Return inspects the current draft. Automatic lens changes and primary in-view actions need no Option setting.

Keyboard setup →
Updating from 1.x?

Path + Tab and Option-Tab replace f and d. Reload with exec zsh after updating. Personal add-ons remain in your private configuration space.

Migration guide →
Prefer a copy instead of a symlink?

Replace --symlink with --copy in the preview and install commands. Copy mode keeps a managed snapshot; rerun the copy installer after updates. In symlink mode, shared changes arrive with a Git pull. Your private files stay separate in either mode.
